# Сопутник

Единая платформа сопровождения и профессиональной адаптации молодых людей 14–23 лет. Рабочая клиентская демоверсия по предоставленным схемам. Сотрудничество с фондом «Вклад в будущее» планируется; партнёрство не подтверждается этим проектом.

## Запуск

Нужен Node.js 20+ (проверено на 24).

```sh
npm ci
npm start
```

Приложение работает на порту 3000. `PORT` позволяет выбрать другой порт. Для самого приложения нет внешних runtime-зависимостей. Можно также разместить `index.html`, `app.js`, `style.css`, `favicon.svg` на статическом хостинге; пути относительные.

## Что работает

- Анкета: возраст 14–23, интересы, пять сфер жизни.
- Разные возрастные сценарии: 14–17 — согласование карьерных откликов куратором; 18–23 — самостоятельный трек. Помощь доступна всем.
- «Мост в будущее»: подбор первого шага по выбранным предпочтениям.
- Личный план, отметки выполнения, рекомендации эксперта/ментора, сохранение и скачивание резюме.
- Каталог примерных курсов, стажировок и работы с возрастными ограничениями и локальными откликами.
- Планирование встреч с проверкой будущей даты.
- «Помощь сейчас»: сценарный помощник, демообращения, очередь координатора со статусами.
- Деморазделы куратора, ментора, эксперта, координатора и бизнеса; адаптивная вёрстка.

Все изменения сохраняются в localStorage текущего браузера. Для очистки: «Моя анкета» → «Удалить демоданные». Не вводите реальные персональные данные. Переключатель ролей — средство демонстрации, а не авторизация. Пользователи в разных браузерах не видят данные друг друга.

## Проверки

```sh
npx playwright install --with-deps chromium
npm start # в отдельном терминале
npm test
```

Тест использует системный `/usr/bin/chromium`, если он установлен, иначе Chromium Playwright. Проверяет сохранение анкеты, запрет/разрешение отклика несовершеннолетнего, экранирование пользовательского текста, резюме, профориентацию, помощника, очередь координатора и мобильную ширину. Скриншоты пишутся в `/tmp`.

## Границы реализации

СберID, Работа.ру, GigaChat/другой ИИ, уведомления и автоматическая эскалация НЕ подключены. Ссылка на Работа.ру открывает сайт без передачи резюме. Встречи и обращения никому не отправляются. Помощник использует локальные правила, не языковую модель. Для экстренной помощи показан номер 112; платформа не вызывает службы.

Для промышленной версии необходимы серверная авторизация и RBAC, база данных, согласия и проверка полномочий кураторов, аудит, политика обработки данных несовершеннолетних, договорённости с партнёрами, подключение API, защищённые уведомления и реально обслуживаемая очередь помощи. Архитектура и следующие этапы описаны в [docs/architecture.md](docs/architecture.md).

## Автопубликация GitHub Pages

Workflow `.github/workflows/check.yml` проверяет приложение, затем публикует только четыре публичных файла на Pages. Публикация выполняется после успешных тестов при push в `main`; pull request только проверяется. Можно запустить вручную через Actions → Browser checks → Run workflow.

Один раз в Settings → Pages → Build and deployment → Source выберите **GitHub Actions** (нужны права администратора репозитория). Адрес после успешного развёртывания: https://fot-manager-training.github.io/social-project/ . Пока job `Publish to GitHub Pages` не завершился успешно, доступность адреса не подтверждена. Секреты и персональные токены для самого workflow не нужны; используются ограниченные права `GITHUB_TOKEN` и OIDC.

### Версии файлов и кэш

`npm run build` создаёт `_site/`: CSS, JavaScript и favicon получают имена с хэшем содержимого. При изменении дизайна браузер загружает новые адреса файлов автоматически. Pages публикует эту сборку, а не исходные файлы. Проверка после публикации сравнивает HTML и все файлы сборки с опубликованными; браузерный CI проверяет именно сборку.
